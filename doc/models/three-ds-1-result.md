
# Three DS 1 Result

## Structure

`ThreeDS1Result`

## Fields

| Name | Type | Tags | Description | Getter | Setter |
|  --- | --- | --- | --- | --- | --- |
| `cavv` | `?string` | Optional | The cardholder authentication value (base64 encoded). | getCavv(): ?string | setCavv(?string cavv): void |
| `cavvAlgorithm` | `?string` | Optional | The CAVV algorithm used. | getCavvAlgorithm(): ?string | setCavvAlgorithm(?string cavvAlgorithm): void |
| `eci` | `?string` | Optional | 3D Secure Electronic Commerce Indicator (ECI). | getEci(): ?string | setEci(?string eci): void |
| `threeDAuthenticatedResponse` | `?string` | Optional | The authentication response from the ACS. | getThreeDAuthenticatedResponse(): ?string | setThreeDAuthenticatedResponse(?string threeDAuthenticatedResponse): void |
| `threeDOfferedResponse` | `?string` | Optional | Whether 3D Secure was offered or not. | getThreeDOfferedResponse(): ?string | setThreeDOfferedResponse(?string threeDOfferedResponse): void |
| `xid` | `?string` | Optional | A unique transaction identifier generated by the MPI on behalf of the merchant to identify the 3D Secure transaction, in `Base64` encoding. | getXid(): ?string | setXid(?string xid): void |

## Example

```php
use AdyenLib\Models\Builders\ThreeDS1ResultBuilder;

$threeDS1Result = ThreeDS1ResultBuilder::init()
    ->cavv('cavv2')
    ->cavvAlgorithm('cavvAlgorithm8')
    ->eci('eci6')
    ->threeDAuthenticatedResponse('threeDAuthenticatedResponse8')
    ->threeDOfferedResponse('threeDOfferedResponse2')
    ->build();
```
