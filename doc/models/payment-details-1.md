
# Payment Details 1

## Structure

`PaymentDetails1`

## Fields

| Name | Type | Tags | Description | Getter | Setter |
|  --- | --- | --- | --- | --- | --- |
| `amount` | [`Amount110`](../../doc/models/amount-110.md) | Required | The amount of the payment. | getAmount(): Amount110 | setAmount(Amount110 amount): void |
| `counterparty` | [`Counterparty11`](../../doc/models/counterparty-11.md) | Required | Contains information about the party that receives the payment funds. | getCounterparty(): Counterparty11 | setCounterparty(Counterparty11 counterparty): void |

| `expiresAt` | `DateTime` | Required | The expiration date of the payment in ISO DateTime format, as described on ISO 20022 (YYYY-MM-DDThh:mm:ss.sss+/-hh:mm).<br><br>Example: **2025-12-30T14:15:30+01:00** | getExpiresAt(): \DateTime | setExpiresAt(\DateTime expiresAt): void |

## Example

```php
use AdyenLib\Models\Builders\PaymentDetails1Builder;
use AdyenLib\Models\Builders\Amount110Builder;
use AdyenLib\Models\Builders\Counterparty11Builder;
use AdyenLib\Models\Builders\AccountHolder11Builder;
use AdyenLib\Models\Builders\AccountIdentification1Builder;
use AdyenLib\Utils\DateTimeHelper;

$paymentDetails1 = PaymentDetails1Builder::init(
    Amount110Builder::init(
        'EUR',
        499
    )->build(),
    Counterparty11Builder::init(
        AccountHolder11Builder::init(
            'John Doe'
        )->build(),
        AccountIdentification1Builder::init()
            ->type('AccountIdentification1')
            ->build()
    )->build(),
    'Payment at MyShop. ref:12345678',
    DateTimeHelper::fromRfc3339DateTimeRequired('2025-12-30T14:15:30+01:00')
)->build();
```
